# Конфиги сервера (только сервер)

Копия файлов из папки сервера `Сервер Война и Колонии\config`. Клиентам ставить не нужно — квесты FTB Quests приходят с сервера.

- `config/ftbquests/quests/` — все главы и таблицы наград (квест-пак 2026-11-05: «Путь колонии» — жезл строителя отдельным квестом, окно J, хижины через достижения, казармы ×10, чародей → ад → алхимик, /colonybuy, ветка «Друзья в колонии»).
- `config/colonybuy/colonybuy-common.toml` — /colonybuy работает и во время войны/осады/рейда (`blockDuring* = false`).
