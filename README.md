# Клиент сервера «Война и Колонии» (Minecraft 1.20.1, Forge 47.4.28)

## Скачать
- Полная сборка модов (81 jar): [client-mods-1.20.1-colonies-20261105.zip](https://github.com/Chuchumbrik/maincraft_1.20.1_colony/releases/download/client-20261105/client-mods-1.20.1-colonies-20261105.zip)
- Только наши моды (12 jar): [custom-mods-only.zip](https://github.com/Chuchumbrik/maincraft_1.20.1_colony/releases/download/client-20261105/custom-mods-only.zip)
- Все релизы: https://github.com/Chuchumbrik/maincraft_1.20.1_colony/releases

## Установка
1. Установите Minecraft **1.20.1** с **Forge 47.4.28** (в TLauncher выберите версию «Forge 1.20.1» → 47.4.28, или создайте свою версию, например `1.20.1 Колонии`).
2. Скачайте `client-mods-1.20.1-colonies-20261105.zip` из Releases.
3. Распакуйте содержимое папки `mods` из архива в `%APPDATA%\.minecraft\versions\<ваша версия>\mods` (у нас: `versions\1.20.1 Колонии\mods`). Старые моды из этой папки лучше убрать, чтобы не было дублей разных версий.
4. Выделите игре 6–8 ГБ памяти и запускайте.

## Важно
- Версии модов на клиенте и сервере должны совпадать. Особенно это касается **colonyboard 1.2.0** (окно колонии на J): при разной версии на сервер не зайти. То же для других модов, которые стоят с обеих сторон (MineColonies, Recruits, Epic Fight, Iron's Spells и т.д.).
- При обновлении сборки скачивайте новый архив целиком.
- `custom-mods-only.zip` — только наши собственные моды/патчи, для тех, у кого остальное уже стоит.

## Предупреждение
Архив содержит сторонние моды, перезалитые исключительно для удобства игроков этого частного сервера. Все права принадлежат их авторам; оригиналы есть на CurseForge и Modrinth — поддержите авторов. Если вы автор мода и против размещения, напишите — файл будет удалён.

## Моды для клиента (папка mods/)

В папке [`mods/`](mods/) лежит полный набор клиентских модов (Forge 1.20.1).

1. Нажми **Code → Download ZIP** (или `git clone`), либо скачай нужные jar прямо из `mods/`.
2. Скопируй все jar из `mods/` в папку `mods` своего профиля Minecraft.
3. Играешь.

Для друзей в **Releases** по-прежнему лежит готовый zip с тем же набором.
